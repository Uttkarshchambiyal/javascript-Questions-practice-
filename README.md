## 📌 About

A growing collection of **JavaScript practice questions** implemented as small, functional parts of a website. Each question sharpens:

- 🧠 Logic building & problem decomposition
- 🌐 Interactive front-end features with vanilla JS
- 📱 Responsive behavior & UI patterns
- ⚙️ DOM manipulation & event handling

---

## 🎯 Topics Covered

| Category | Examples |
|---|---|
| 🔁 **Loops & Conditions** | FizzBuzz, countdown timers |
| 🎮 **DOM Manipulation** | Dynamic lists, color changers |
| 📝 **Forms & Validation** | Input validators, form handlers |
| 🎨 **CSS + JS Combos** | Toggles, modals, accordions |
| 🔢 **Array Methods** | filter, map, reduce exercises |

---

## 🛠️ Tech Used

- **HTML5** — Structure
- **CSS3** — Styling & responsiveness
- **Vanilla JavaScript** — Logic & interactivity

---

## 🚀 How to Run

```bash
# Clone the repo
git clone https://github.com/Uttkarshchambiyal/javascript-Questions-practice-.git

# Open any HTML file directly in your browser
open index.html
```

No build step needed — just open the `.html` files!
